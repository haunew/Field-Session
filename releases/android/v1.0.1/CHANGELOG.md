# v1.0.1

**Release Date / 发布日期**: 2026-10-19

## Changes / 变更

- Starting a session no longer writes a duplicate location. / 开始会话不再写入重复的定位点。
- The address is filled in after location is allowed the first time. / 首次允许定位后可以取得地址。
- Addresses near a place you have already visited are reused. / 去过的地方附近会复用已有地址。
- Deleting a session also deletes its photos. / 删除会话时会一并删除该会话的照片。
- The PDF button opens the system print sheet. Use Share to send the file. / PDF 按钮打开系统打印；分享文件请点分享。
